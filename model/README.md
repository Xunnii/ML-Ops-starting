# Model

Folder ini digunakan untuk menyimpan kode dan artefak yang berkaitan dengan model Machine Learning.

## Fungsi

- Menyimpan kode training model.
- Menyimpan kode inference.
- Menyimpan artefak model sesuai kebutuhan project.

## Development Workflow

1. Menyiapkan dataset untuk training.
2. Melakukan training model.
3. Mengevaluasi performa model.
4. Menyimpan model yang telah dilatih.
5. Menggunakan model untuk inference.
