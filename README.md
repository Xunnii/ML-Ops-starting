# MLOps Starter Project

Project ini merupakan struktur awal untuk pengembangan project Machine Learning Operations (MLOps).

## Struktur Project

- `frontend/` - Bagian antarmuka pengguna.
- `backend/` - API dan business logic.
- `model/` - Kode dan artefak model Machine Learning.
- `data/` - Penyimpanan data raw dan processed.
- `tests/` - Pengujian project.
- `docs/` - Dokumentasi teknis.
